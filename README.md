# Star Wars Dashboard

## Overview

Web application to display details of the Star Wars saga films, all powered by the Star Wars API (SWAPI) and enhanced with movie posters from The Movie Database (TMDB).

## Features

- **Carrossel de Filmes** - Exibição dos filmes de Star Wars com transições suaves e reprodução automática.
- **Informações Detalhadas dos Filmes** - Visualize detalhes completos, incluindo sinopse, data de lançamento, diretor, produtor e quantidades de personagens, planetas, espécies, naves e veículos de cada filme.
- **Design Responsivo**

## Technologies Used

- **Vue.js 2** - Progressive JavaScript framework for building user interfaces.
- **Axios** - Promise-based HTTP client for API requests.
- **SCSS/Sass** - CSS preprocessor for enhanced styling capabilities.
- **SWAPI** - Star Wars API for comprehensive universe data.
- **TMDB API** - The Movie Database API for high-quality movie posters.

## Installation

1. Clone the repository:

```bash
git clone <REPOSITORY_URL>
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run serve
```

4. Build for production:

```bash
npm run build
```

## API Integration

This project integrates with two external APIs:

- **SWAPI (Star Wars API)** - Provides comprehensive data about the Star Wars universe
- **TMDB (The Movie Database)** - Supplies high-quality movie posters and additional film data
